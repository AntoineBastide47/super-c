# The target table

`src/target/table.spc` is the only source of target facts. A target is a row of `TARGETS` built by
`targets()` from five parts, each a row of its own table:

| Part | Table | Holds |
|---|---|---|
| `Isa` | `ISAS` | `@arch` name, pointer size, feature model (`fn_features`, `levels`, `ext_flags`), `vector_bytes` (0: the LIR vectorizer stays off), `mul_high`, `simd_backend`, the C intrinsic headers |
| `CallConv` | `CALLCONVS` | the convention's name and C `va_list` size |
| `ObjFormat` | `OBJFORMATS` | section-name rule (`SEC_*`), symbol visibility, `-fPIC`, the soname flag |
| `Os` | `OSES` | `@platform` name, default instruction set, SDK kind (`SDK_*`), sysroot layout (`SYSROOT_*`), whether std provides its C library (`own_libc`), file name affixes, link flags |
| `Debug` | `DEBUGS` | the debug format |

The `Target` row adds the C data model (`long_bytes`, `long_double_bits`, `big_endian`), the red zone,
the page size, the baseline and impossible CPU features, the C compiler's `-target` triple and `cenv`,
the index of its C environment row.

## Adding a row

1. A new part: append its row to its table and give it a constant beside `OS_*`, `ISA_*`, `CC_*`,
   `OBJ_*`. The `OSES` and `ISAS` order is the bit order of `@platform` and `@arch`: append, never
   reorder (a compiled `@platform` mask would change meaning).
2. The `Target` row: build it with `row(...)` and the helpers (`x86`, `a64`, `apple`) in `targets()`,
   and raise the `TARGETS` length.
3. The C environment: `src/bindgen/ctarget_data.spc` is generated by `scripts/gen_ctarget.py` from the
   reference clang and the target's SDK headers; regenerate it, do not edit it. Row `i` is the C
   environment of `TARGETS` row `i`.
4. CPU features of a new instruction set: rows in `src/ir/cpu_features.spc` (the source of
   `std::cpu::Feature`; a row's index is its bit). The target row names its baseline with `feats`.
5. std's axis enums: the compiler builds `std::target` from the table
   (`tests/codegen/target_table_test.spc` checks the names and discriminants). `std/target.spc` serves
   releases before the table: add the new names there too, in the table's order.

## What reads the table

- `find`, `target_of`, `isa`, `os`, `callconv_of`, `obj_of`: the row and its parts for `(os, isa)`.
- `axis_names`, `axis_index`: the `--target=` and `--arch=` names (`src/main.spc` parses them).
- `baseline`: the features a build has without `--target-feature=`.
- `host_os`, `host_isa`: the compiling machine's pair.

Shared code tests a fact (`tgt::isa(isa).vector_bytes != 0`), never a name. A new fact is a new field
with a value in every row.
